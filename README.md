# Love Being Jewish

First version of the website for `www.lovebeingjewish.com`.

## What Is Included

- Single-page homepage
- Responsive layout
- Text-only design: `LOVE. BEING. JEWISH.`
- Production build and rendered HTML tests

## Local Preview

```bash
npm install
npm run dev
```

Open `http://localhost:3000/`.

## Verify

```bash
npm test
```

## GitHub Next Step

Create a new GitHub repository, likely named `lovebeingjewish`, then connect
this local project to it and push the `main` branch.

The GoDaddy domain should only be pointed away from Squarespace after the new
GitHub-hosted or other hosted site is live and verified.
